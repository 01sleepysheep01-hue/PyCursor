启动一个耗时测试，点击“停止”。说明后台会取消当前工具、终止 Windows 命令树，

网络允许，用手机微信文件传输助手打开局域网地址并发送一条只读任务。演示完点击
“停止 H5”，避免暴露工作区执行能力。
