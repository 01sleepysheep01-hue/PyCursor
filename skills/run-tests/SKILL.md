## 什么时候用

用户要求验证代码、复现测试失败或定位测试报错时使用。

## 步骤

1. 根据 README 和 pyproject.toml 判断项目测试命令。
2. 先运行一次测试，不要一上来就增加大量详细输出参数。
3. 最多读取 3 个失败用例的 traceback。
4. 按“哪个用例 / 期望什么 / 实际什么 / 最可能原因”总结。
5. 本技能只报告结果，不修改代码。

## 不要做什么

- 不要为了掩盖失败修改测试。
- 不要回注完整 traceback。
- 不要在任务没有结论时宣布完成。

## 怎么算做完了

- 已给出测试通过与失败数量。
- 每个失败用例都有期望、实际和原因。
- 输出中包含明确的下一步建议。
